# Week 6 MVP Plan

## Defined problem

Users need a repeatable way to sort a messy folder of downloaded files without manually creating category folders or risking accidental overwrites.

## MVP goal

Given a source directory, classify files by extension, show a dry-run plan, and move files into category folders with explicit conflict behavior.

## Completed for Week 6

- topic, scope, architecture, and repository structure;
- runnable Python package and command-line entry point;
- three technology areas selected and documented;
- validation, dry-run mode, conflict handling, and automated tests;
- reproducible installation and run instructions.

## Remaining before final version

- integrate SQLite history recording into the CLI and add undo;
- Tkinter approval interface;
- reports and statistics;
- broader test coverage, packaging polish, and final presentation.
